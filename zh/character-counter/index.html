首页chevron_right工具chevron_right字数统计

申请材料、meta 描述、社交平台的帖子都有长度限制，但各自计算的方式并不一致。这里在一个界面上同时显示含空格与不含空格的字数、词数、字节数和稿纸页数。

list_alt 字数统计 使用方法

  1. 输入或粘贴文本，所有数值会随输入实时重新计算。
  2. 先看最醒目的两个数字：含空格和不含空格。
  3. 填写字数上限或选择预设，即可显示进度条和实时剩余字数。
  4. 粘贴到表单之前，可用整理按钮合并连续空格、删除空行或合并为一行。

lightbulb 实用提示

  • 相信数字之前，先确认那个表单是否计算空格。1,000 字的文章里，含不含空格常常相差 150 字左右。
  • 字节限制不等于字数限制。较早的系统按双字节计算一个全角字符，那类表单所说的正是双字节的数值。
  • 表情符号等基本区之外的字符在这里算一个字，但在 UTF-8 中占四个字节。短帖子仍被判为超长的原因就在这里。
  • 稿纸按每页 200 字换算。

help_outline 常见问题

输入的内容会被发送出去吗？

不会。计算在浏览器内用 JavaScript 完成，未写完的稿件或涉密草稿不会离开你的设备。

和 Word 的数字不一样

Word 统计词的规则不同，还可能排除脚注、页眉和文本框。字数方面，只要对齐含空格或不含空格的设置，通常是一致的。

词是怎么统计的？

按空格切分，这与大多数表单和编辑器的做法一致。对于不使用空格分词的语言，字数比词数更有参考价值。

本页所有功能都在浏览器中运行。无需注册、无需上传、没有使用限制。
