首页chevron_right工具chevron_rightPDF 合并·拆分·旋转

把两个 PDF 合起来、抽掉一页、或者把一叠照片变成一份文档，通常都要把文件传到一个没听说过的网站，然后指望它事后会删掉。这个页面在浏览器里完成这些事。把文件放进来，调整页面顺序，保存即可。数据不离开你的电脑这一点，在那份 PDF 是合同、工资单或护照扫描件时意义完全不同。

list_alt PDF 合并·拆分·旋转 使用方法

  1. 把文件拖到页面上，或者点击选择。PDF 和图片可以混着放，一次放多个也没问题。
  2. 所有文件的所有页面会按添加顺序铺成缩略图。
  3. 拖动缩略图来移动位置。屏幕上瓷砖的顺序，就是保存出来的 PDF 的页面顺序。
  4. 点击页面进行选择。选中的页面可以用上方按钮一起旋转或删除，瓷砖上的旋转按钮只转那一页。
  5. 把全部页面存成一个 PDF 就是合并，只挑选部分页面保存就是拆分。两个按钮都只写出新文件，不会改动原件。
  6. 把页面导出为图片会得到一个 ZIP，里面是按屏幕两倍分辨率渲染的 PNG。当别人只要第 4 页的图而不是整份文档时很好用。

lightbulb 实用提示

  • 要把一个 PDF 分成两个，读入一次后选中前半保存，再反选一次保存即可。原文件始终不变。
  • 旋转是叠加在页面原有角度之上的。本来就横躺着的页面，最终会和缩略图里看到的一样。
  • 图片会变成与图片尺寸一致的整页。放入一组手机照片，得到的文档不会每张周围都留白边。
  • 文档上限为 400 页。再多的话，光是缩略图就会耗尽标签页的内存，请先把文件拆开分批处理。
  • 加密的 PDF 在解除密码前无法读取。浏览器没有办法猜出密码，这个工具会明确告诉你，而不是悄悄失败。

help_outline 常见问题

我的文件会被上传吗？

不会。文件由这个标签页里运行的 JavaScript 直接读取，新的 PDF 也是在你自己电脑的内存中拼装的。既没有接收文件的服务器，也没有用来存放它们的账号。如果你不想只听我们说，可以在放入文件之前打开浏览器的网络面板，亲眼看着什么请求都没有发出去。

画质会下降吗？

PDF 页面不会。合并不是重新渲染，而是把原来的页面对象整个复制过来：同样的字体、同样的矢量、同样的内嵌图片，清晰进来就清晰出去。唯一需要考虑画质的是「导出为图片」，那一步会按屏幕两倍分辨率重新光栅化。

为什么合并后的文件比原来加起来还大？

因为每一页都会带着自己的资源。两份都嵌了同一款字体的文档合并后，结果文件里就有两份该字体。好处是没有任何东西被丢弃或重新编码；代价是文件体积的算术不那么整齐。

能编辑 PDF 里的文字吗？

不能。这个工具在页面层面工作：重排、旋转、删除、合并。要改动页面里的文字，需要重新排版、替换字体、重写内容流，那是另一类工具，而且要重得多。如果目的是把文字取出来，导出成图片再走 OCR 会更快。

手机上能用吗？

能用，只是桌面端更顺手。触摸选择和排序都可以，导出结果也一样。大文档在手机上更吃力，只是因为手机标签页能用来绘制缩略图的内存更少。

本页所有功能都在浏览器中运行。无需注册、无需上传、没有使用限制。
