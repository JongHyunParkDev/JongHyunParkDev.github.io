首页chevron_right工具chevron_right语音转文字 (STT)

对着浏览器说话就能得到文字，无需 API 密钥和账号。适合记录长篇笔记，或不方便打字的时候。

list_alt 语音转文字 (STT) 使用方法

  1. 选择语言。
  2. 点击录音，并在浏览器询问时允许使用麦克风。
  3. 正常说话，文字会随说话逐步累积。
  4. 停止后复制或修改文本。

lightbulb 实用提示

  • 标点要念出来。多数引擎里说「逗号」「句号」「换行」会插入符号而不是文字。
  • 把麦克风放近、在安静的地方说，比放慢语速更有效。背景噪音对准确率的影响大于语速。
  • 识别质量因浏览器而异，目前 Chrome 和 Edge 处理得最好。

help_outline 常见问题

哪些浏览器支持？

基于 Web Speech API，Chrome 和 Edge 支持良好，Safari 部分支持，Firefox 默认不支持。

语音会被发送到服务器吗？

本页面不会发送，但浏览器的语音识别可能会把音频转发给厂商的服务，Chrome 就是这样实现的。请避免听写敏感内容。

录音会自己停止

浏览器在持续静音一段时间后会结束识别会话，重新开始即可继续。

本页所有功能都在浏览器中运行。无需注册、无需上传、没有使用限制。
