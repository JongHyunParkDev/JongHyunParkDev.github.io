这是什么？

一组为做 Web 开发的人准备的小而专注的工具——就是那种你在工作途中临时搜索来用、五分钟后又关掉的工具。所有工具都完全在浏览器中运行：无需注册、无需上传、没有使用限制，你粘贴的内容也不会发送到任何服务器。

这里都有什么

build 工具
通用工具：带会议时间规划的世界时钟、科学计算器、语音朗读与语音输入、Markdown 转换，以及二维码和条形码的生成与识别。
account_balance_wallet 薪资·理财
pages.main.about.money
casino 模拟器
模拟器：把彩票开奖跑上几千次，不是听别人报一个概率数字，而是直接看到它实际是什么样子。
terminal 开发工具
日常开发工具：格式化与校验 JSON、解码 JWT、读懂 cron 表达式、从 API 响应生成类型、把 cURL 命令转成代码、计算文件哈希，以及查清 422 到底是什么意思。
brush 设计
视觉相关：按 WCAG 检查颜色对比度、制作多层阴影与渐变、把图片压缩成 WebP，以及用一张图生成整套 favicon。
smart_toy AI
结合 MBTI 与四柱八字的 AI 关系分析（仅供娱乐）。
sports_esports 游戏
等构建跑完时可以玩的几个浏览器小游戏：合成水果、圈地、翻牌记忆和扫雷。

键盘快捷键

在任意页面按 Ctrl+K（Mac 为 ⌘K）打开命令面板，直接跳转到某个工具。单独按 / 键也可以。方向键移动，Enter 打开，Esc 关闭。点击星标可将工具固定到侧边栏。

为什么全部在本地运行

这些工具处理的正是你不该粘贴到陌生服务器上的数据：生产环境的 JSON、访问令牌、客户记录、内部配置。在你自己机器上用 JavaScript 完成处理，这个顾虑就彻底消失了——打开浏览器的网络面板，你会看到什么请求都没有发生。
