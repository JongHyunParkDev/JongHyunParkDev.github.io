首页chevron_right工具chevron_rightMarkdown Html 转换器

在 Markdown 和 HTML 之间双向转换，并提供实时预览。适合在 CMS、README 和邮件之间搬运内容。

list_alt Markdown Html 转换器 使用方法

  1. 一侧粘贴 Markdown，另一侧粘贴 HTML。
  2. 观察转换结果和预览的更新。
  3. 复制你需要的格式。

lightbulb 实用提示

  • HTML 转 Markdown 本质上会丢失信息。样式、类名和布局标记在 Markdown 中没有对应写法，会被丢弃。发布前请检查结果。
  • 要发现表格错乱或未闭合的代码块，预览是最快的方式。
  • Markdown 有不同方言。表格、任务列表和删除线是 GitHub 扩展而非原始规范，并非所有渲染器都支持。

help_outline 常见问题

使用哪种 Markdown 方言？

CommonMark 加上常见的 GitHub 扩展，这是多数工具和静态站点生成器所预期的组合。

Markdown 中的原始 HTML 会保留吗？

转换为 HTML 时内联 HTML 会原样通过。反向转换时不受支持的元素会被简化或删除。

可以转换整个文件吗？

把内容粘贴到编辑器即可。转换的是文本而不是文件。
