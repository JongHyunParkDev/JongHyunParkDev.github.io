首页chevron_right设计chevron_right图片转换与压缩

把图片批量转换并压缩为 WebP、PNG 或 JPEG，全程不上传任何文件。适合把截图和照片压到不会拖垮页面加载的体积。

list_alt 图片转换与压缩 使用方法

  1. 把图片文件拖到方框上、点击选择，或用 Ctrl+V 从剪贴板粘贴。
  2. 选择输出格式和质量，需要的话再指定最大宽度或高度。
  3. 点击全部转换。每张卡片会显示新的尺寸、体积以及减少了多少。
  4. 逐个保存，或把整批下载为 ZIP。

lightbulb 实用提示

  • WebP 质量 75~85 通常是最佳点：肉眼与原图难以区分，体积却小很多，而且现行浏览器全部支持。
  • 缩小尺寸比重新编码有效得多。以 800px 显示的 4000px 截图应该缩放，而不只是压缩。
  • PNG 是无损格式，质量设置不起作用。PNG 只有缩小尺寸才能减小体积，想更小请转成 WebP。
  • 把透明 PNG 转成 JPEG 会用白色填充透明区域，因为 JPEG 没有 alpha 通道。要保留透明请用 WebP 或 PNG。

help_outline 常见问题

图片会上传到服务器吗？

不会。解码和重新编码都在浏览器内的画布上完成。文件不会离开你的电脑，因此除了可用内存之外没有体积限制。

转换后反而变大了

多半是原图已经压得很好却用了高质量转换，或者把简单图形从 PNG 转成了 JPEG。这种情况下节省比例会显示为红色，请降低质量或保留原图。

可以输出 AVIF 吗？

暂不提供 AVIF 编码，因为浏览器在画布上编码 AVIF 的支持仍不统一。读取 AVIF 并转换成 WebP、PNG、JPEG 是可以的。
