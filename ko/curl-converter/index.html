홈chevron_right개발 도구chevron_rightcURL 변환기

브라우저 개발자도구에서 복사한 요청을 바로 동작하는 코드로 바꿉니다. cURL 명령을 붙여넣으면 fetch, axios, Python requests, Go 코드가 나오고, 그 명령이 실제로 무엇을 보내는지도 함께 정리해 줍니다.

list_alt cURL 변환기 사용법

  1. 브라우저에서 개발자도구 → Network를 열고 요청을 우클릭해 Copy → Copy as cURL을 누릅니다.
  2. 왼쪽에 붙여넣습니다. 백슬래시로 줄이 이어진 여러 줄 명령도 그대로 처리됩니다.
  3. 해석된 요청에서 메서드, URL, 쿼리스트링, 헤더, 본문이 예상과 맞는지 확인합니다.
  4. fetch, axios, Python, Go, 정규화된 cURL 중에서 탭을 고르고 코드를 복사합니다.

lightbulb 알아두면 좋은 점

  • 코드가 필요 없을 때도 해석된 요청 패널은 볼 만합니다. 긴 URL에서 쿼리스트링을 떼어내고 헤더를 한 줄씩 나열해 주므로 Content-Type이 잘못된 경우가 바로 눈에 띕니다.
  • 따옴표 방식을 가리지 않아서 윈도우 cmd에서 복사한 것과 유닉스 셸에서 복사한 것 모두 해석됩니다.
  • 요청 내용에 영향을 주지 않는 -s, -v, --compressed 같은 플래그는 URL로 오인하지 않고 인식한 뒤 무시합니다.
  • JSON 본문은 생성된 코드에서 보기 좋게 정렬되며, Python 대상에서는 True/False/None으로 바꿔 줍니다.

help_outline 자주 묻는 질문

헤더나 토큰이 전송되나요?

아니요. 해석과 코드 생성이 전부 브라우저 안에서 이루어지므로 붙여넣은 명령의 Authorization 헤더가 기기 밖으로 나가지 않습니다. 다만 어떤 도구든 운영 토큰을 붙여넣는 것은 조심하는 편이 좋습니다.

파일 업로드도 되나요?

-F/--form 필드는 해석해서 자바스크립트에서는 FormData로, Python에서는 files=로 만들어 줍니다. 다만 cURL 명령만으로는 실제 파일 내용을 복원할 수 없으므로 파일 자체는 코드에서 직접 붙여야 합니다.

Basic 인증이 왜 btoa(...)로 나오나요?

무엇이 인코딩되는지 보이고 변수로 바꾸기 쉽게 하기 위해서입니다. Python과 Go에서는 각 언어의 관용적인 방식인 auth=()와 req.SetBasicAuth()를 씁니다.

이 페이지의 모든 기능은 브라우저에서 실행됩니다. 가입도, 업로드도, 사용 제한도 없습니다.
