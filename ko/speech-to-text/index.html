음성 텍스트 변환 (STT)

브라우저에 말하면 텍스트로 받아 줍니다. API 키도 계정도 필요 없습니다. 긴 메모를 남기거나 타이핑이 곤란할 때 유용합니다.

받아쓰기는 Web Speech API를 씁니다. 크롬과 엣지에서는 브라우저가 음성을 구글 인식 서비스로 보내 결과를 받아 오고, 다른 브라우저에서는 기능 자체가 없을 수 있습니다. 그럴 때는 조용히 실패하는 대신 지원하지 않는다고 표시합니다. 녹음은 이 사이트로 전송되거나 저장되지 않지만, 브라우저가 어딘가로 보낸다는 사실은 알고 쓰시는 편이 좋습니다.

인식 품질은 설정보다 마이크와 방 상태에 훨씬 크게 좌우됩니다. 시작 전에 언어를 맞추는 것이 중요합니다. 영어 모델은 한국어 발화에 대해 자신 있게 엉뚱한 문장을 내놓습니다. 문장부호는 추론하지 않으므로 결과는 끊기지 않은 덩어리로 나오고, 뒤에 한 번 다듬는 과정이 필요합니다.

list_alt 음성 텍스트 변환 (STT) 사용법

  1. 언어를 고릅니다.
  2. 녹음을 누르고 브라우저가 물으면 마이크 권한을 허용합니다.
  3. 평소처럼 말하면 말하는 동안 텍스트가 쌓입니다.
  4. 멈춘 뒤 복사하거나 다듬습니다.

lightbulb 알아두면 좋은 점

  • 문장부호는 소리 내어 말하세요. 대부분의 엔진에서 "쉼표", "마침표", "줄바꿈"이라고 하면 글자가 아니라 기호로 들어갑니다.
  • 천천히 말하는 것보다 마이크를 가까이 두고 조용한 곳에서 하는 편이 훨씬 낫습니다. 속도보다 배경 소음이 정확도를 더 많이 깎습니다.
  • 인식 품질은 브라우저마다 다릅니다. 현재는 Chrome과 Edge가 가장 잘 처리합니다.

help_outline 자주 묻는 질문

어떤 브라우저에서 되나요?

Web Speech API를 사용하며 Chrome과 Edge에서 잘 지원되고, Safari는 부분적이며, Firefox는 기본적으로 지원하지 않습니다.

음성이 서버로 전송되나요?

이 페이지가 보내지는 않지만, 브라우저의 음성 인식이 오디오를 제조사 서비스로 전달할 수 있습니다. Chrome이 그렇게 동작합니다. 민감한 내용은 받아쓰지 마세요.

녹음이 저절로 멈춥니다

브라우저는 일정 시간 소리가 없으면 인식 세션을 종료합니다. 다시 시작하면 이어집니다.
