음성 텍스트 변환 (STT)

음성 텍스트 변환
브라우저에 내장된 음성 인식으로 받아쓰기를 합니다. 무료이며 계정도 API 키도 필요 없습니다.
계속 듣기
자동 문장부호
말한 내용이 여기에 표시됩니다.
0 words

브라우저에 말하면 텍스트로 받아 줍니다. API 키도 계정도 필요 없습니다. 긴 메모를 남기거나 타이핑이 곤란할 때 유용합니다.

받아쓰기는 Web Speech API를 씁니다. 크롬과 엣지에서는 브라우저가 음성을 구글 인식 서비스로 보내 결과를 받아 오고, 다른 브라우저에서는 기능 자체가 없을 수 있습니다. 그럴 때는 조용히 실패하는 대신 지원하지 않는다고 표시합니다. 녹음은 이 사이트로 전송되거나 저장되지 않지만, 브라우저가 어딘가로 보낸다는 사실은 알고 쓰시는 편이 좋습니다.

인식 품질은 설정보다 마이크와 방 상태에 훨씬 크게 좌우됩니다. 시작 전에 언어를 맞추는 것이 중요합니다. 영어 모델은 한국어 발화에 대해 자신 있게 엉뚱한 문장을 내놓습니다. 문장부호는 추론하지 않으므로 결과는 끊기지 않은 덩어리로 나오고, 뒤에 한 번 다듬는 과정이 필요합니다.

인식은 두 단계로 도착하고, 이것을 알면 버그처럼 보이던 동작이 설명됩니다. API는 말하는 도중에 잠정 후보를 계속 내보내다가 어구가 정리되면 최종 결과로 바꿔 놓습니다. 그래서 말하는 동안 단어가 나타났다가 바뀌고 가끔은 사라집니다. 그 수정은 모델이 문장의 뒷부분을 근거로 앞부분을 다시 해석하는 과정입니다. 사람이 한 단어를 잘못 듣고 잠시 뒤에 스스로 고치는 것과 같은 일입니다. 잠정 텍스트만 보고 정확도를 판단하면 실제보다 나쁘게 보입니다. 읽어야 할 것은 최종 결과이고, 지나가던 화면보다 눈에 띄게 나은 경우가 많습니다.

받아쓰기 세션은 무한하지 않습니다. 브라우저는 일정 시간 침묵이 이어지면 인식을 멈추고, 연속 모드도 진짜로 계속 도는 것이 아니라 세션을 다시 시작하는 방식입니다. 그래서 긴 받아쓰기는 여러 세션을 이어 붙인 것이 되고, 세션 사이의 틈에 말한 내용은 그냥 사라집니다. 이 기능을 구현한 브라우저에서는 인식에 네트워크 연결도 필요합니다. 마이크는 멀쩡히 녹음하는데도 오프라인이 되면 인식이 완전히 멈춥니다. 두 제약 모두 따로 알려 주지 않고, 잡혔어야 할 말이 잡히지 않은 형태로만 드러납니다.

오류는 예측 가능한 곳에 몰립니다. 고유명사, 제품명, 전문 용어, 약어입니다. 일반 모델이 그것들을 예상할 이유가 없기 때문입니다. 이 API로는 사용자 사전을 넣을 방법이 없으므로, 현실적인 작업 방식은 받아쓰기만 하는 것이 아니라 받아쓰기 뒤에 교정 한 번을 붙이는 것입니다. 문장부호는 추론되지 않으며, 여러 언어가 섞인 발화는 선택된 언어로만 인식됩니다. 영어 모델에 한국어를 들려주면 눈에 띄게 실패하는 대신 그럴듯하고 자신 있는 헛소리를 내놓습니다. 결과 자체가 틀렸다는 신호를 주지 않기 때문에 오히려 더 나쁩니다.

마이크 접근은 이 페이지가 아니라 브라우저의 권한 모델을 따릅니다. 권한은 출처 단위로 부여되고 기억되며, 페이지가 HTTPS로 제공되어야 요청 창이 아예 뜹니다. 탭이나 시스템 트레이의 녹음 표시는 브라우저가 스스로 알리는 것이라 페이지가 무슨 짓을 해도 감출 수 없습니다. 나중에 권한을 회수하는 것도 여기가 아니라 주소창의 자물쇠나 사이트 설정에서 합니다. 요청 창이 아예 뜨지 않는다면 이 출처에 대한 차단이 이미 저장돼 있는 경우가 대부분이고, 그 설정에서 먼저 풀어야 페이지가 다시 물어볼 수 있습니다.

list_alt 음성 텍스트 변환 (STT) 사용법

  1. 언어를 고릅니다.
  2. 녹음을 누르고 브라우저가 물으면 마이크 권한을 허용합니다.
  3. 평소처럼 말하면 말하는 동안 텍스트가 쌓입니다.
  4. 멈춘 뒤 복사하거나 다듬습니다.

lightbulb 알아두면 좋은 점

  • 문장부호는 소리 내어 말하세요. 대부분의 엔진에서 "쉼표", "마침표", "줄바꿈"이라고 하면 글자가 아니라 기호로 들어갑니다.
  • 천천히 말하는 것보다 마이크를 가까이 두고 조용한 곳에서 하는 편이 훨씬 낫습니다. 속도보다 배경 소음이 정확도를 더 많이 깎습니다.
  • 인식 품질은 브라우저마다 다릅니다. 현재는 Chrome과 Edge가 가장 잘 처리합니다.

help_outline 자주 묻는 질문

어떤 브라우저에서 되나요?

Web Speech API를 사용하며 Chrome과 Edge에서 잘 지원되고, Safari는 부분적이며, Firefox는 기본적으로 지원하지 않습니다.

음성이 서버로 전송되나요?

이 페이지가 보내지는 않지만, 브라우저의 음성 인식이 오디오를 제조사 서비스로 전달할 수 있습니다. Chrome이 그렇게 동작합니다. 민감한 내용은 받아쓰지 마세요.

녹음이 저절로 멈춥니다

브라우저는 일정 시간 소리가 없으면 인식 세션을 종료합니다. 다시 시작하면 이어집니다.
