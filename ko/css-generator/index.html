CSS 생성기

박스 섀도우, 그라디언트, 모서리 둥글기, 트랜스폼, 필터를 실시간 미리보기를 보면서 조정하고 완성된 규칙을 복사합니다. 미리보기는 모든 패널의 설정을 합쳐서 보여주므로 한 번에 전체 표면 스타일을 만들 수 있습니다.

그림자, 그라디언트, 변형은 문법은 쉽지만 결과를 머릿속으로 그리기 어려운 속성입니다. 깊이감 있는 그림자와 얼룩처럼 보이는 그림자의 차이는 블러 몇 픽셀과 알파값 한 단계이고, 명세를 아무리 읽어도 직접 보는 것을 대신하지 못합니다.

여기서는 모든 조절값이 미리보기에 즉시 반영되고 그에 해당하는 선언문이 그대로 출력됩니다. 눈으로 정한 값이 곧 붙여 넣을 값입니다. 여러 겹의 그림자, 임의 위치의 색 정지점, 전체 transform 목록을 다루며, 출력은 프레임워크나 전처리기를 전제하지 않는 순수 CSS입니다.

list_alt CSS 생성기 사용법

  1. 박스 섀도우, 그라디언트, 모서리 둥글기, 트랜스폼, 필터 중에서 패널을 고릅니다.
  2. 슬라이더를 움직이면 오른쪽 미리보기가 즉시 반응합니다.
  3. 그림자는 레이어 추가로 여러 겹을 쌓을 수 있습니다. 실제 디자인 시스템이 깊이를 만드는 방식입니다. 레이어를 클릭하면 편집 대상이 바뀝니다.
  4. 오른쪽 아래에서 생성된 CSS를 복사합니다.

lightbulb 알아두면 좋은 점

  • 그림자 프리셋은 한 겹이 아니라 여러 겹으로 되어 있습니다. 카드가 붕 뜬 느낌이 아니라 자연스러워 보이는 이유가 이것입니다. 프리셋에서 시작해 조정하세요.
  • 탭을 바꿔도 작업한 내용은 사라지지 않습니다. 미리보기와 복사되는 규칙에는 항상 모든 패널이 반영됩니다.
  • 미리보기를 박스와 텍스트로 전환하면 그라디언트를 배경이 아니라 글자 채우기로 확인할 수 있습니다.
  • 미리보기 위의 색상 견본으로 캔버스 색을 바꿔서, 실제로 놓일 배경 위에서 그림자를 확인하세요.

help_outline 자주 묻는 질문

그림자 불투명도가 왜 알파값이 아니라 퍼센트인가요?

드래그하면서 감을 잡기 쉽기 때문입니다. 생성된 CSS는 일반적인 rgba() 알파로 변환되므로 그대로 손으로 고쳐도 됩니다.

그라디언트를 글자색으로 쓸 수 있나요?

됩니다. 미리보기를 텍스트로 바꾸면 확인할 수 있습니다. 실제 CSS에서는 background-clip: text와 투명한 글자색이 함께 필요합니다.

벤더 프리픽스가 필요한가요?

아니요. box-shadow, 그라디언트, border-radius, transform, filter 모두 현재 쓰이는 브라우저에서 프리픽스 없이 동작합니다.
