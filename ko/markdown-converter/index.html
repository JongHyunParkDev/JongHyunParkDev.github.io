마크다운을 HTML로, HTML을 마크다운으로 실시간 미리보기와 함께 변환합니다. CMS와 README, 이메일 사이에서 내용을 옮길 때 씁니다.

list_alt Markdown Html 변환기 사용법

  1. 한쪽에 마크다운을, 다른 쪽에 HTML을 붙여넣습니다.
  2. 변환 결과와 미리보기가 갱신되는 것을 봅니다.
  3. 필요한 형식을 복사합니다.

lightbulb 알아두면 좋은 점

  • HTML에서 마크다운으로 가는 변환은 본질적으로 손실이 있습니다. 스타일, 클래스, 레이아웃 마크업은 마크다운에 대응하는 것이 없어 사라집니다. 게시 전에 결과를 확인하세요.
  • 깨진 표나 닫히지 않은 코드 블록을 잡는 데는 미리보기가 가장 빠릅니다.
  • 마크다운은 방언마다 다릅니다. 표, 체크박스, 취소선은 원래 명세가 아니라 GitHub 확장이라 모든 렌더러가 지원하지는 않습니다.

help_outline 자주 묻는 질문

어떤 마크다운 방언을 쓰나요?

CommonMark에 흔히 쓰이는 GitHub 확장을 더한 형태입니다. 대부분의 도구와 정적 사이트 생성기가 기대하는 조합입니다.

마크다운 안의 HTML은 유지되나요?

HTML로 변환할 때 인라인 HTML은 그대로 통과합니다. 반대로 변환할 때는 지원되지 않는 요소가 단순화되거나 제거됩니다.

파일 전체를 변환할 수 있나요?

내용을 편집기에 붙여넣으면 됩니다. 파일이 아니라 텍스트를 변환합니다.

이 페이지의 모든 기능은 브라우저에서 실행됩니다. 가입도, 업로드도, 사용 제한도 없습니다.
