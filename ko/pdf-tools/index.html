PDF 합치기·분할·회전

PDF 두 개를 합치거나, 한 페이지를 빼거나, 사진 여러 장을 문서 하나로 만드는 일은 보통 처음 보는 사이트에 파일을 올리고 알아서 지워 주기를 바라는 것으로 끝납니다. 이 페이지는 그 작업을 브라우저 안에서 합니다. 파일을 놓고, 페이지 순서를 바꾸고, 저장하면 됩니다. 파일이 컴퓨터 밖으로 나가지 않는다는 점은 그 PDF가 계약서나 급여명세서, 여권 스캔본일 때 의미가 달라집니다.

list_alt PDF 합치기·분할·회전 사용법

  1. 파일을 페이지 위에 끌어다 놓거나 눌러서 고릅니다. PDF와 이미지를 섞어도 되고, 여러 개를 한 번에 올려도 됩니다.
  2. 올린 모든 파일의 모든 페이지가 추가한 순서대로 썸네일로 펼쳐집니다.
  3. 썸네일을 끌어서 옮깁니다. 화면에 보이는 타일 순서가 곧 저장될 PDF의 페이지 순서입니다.
  4. 페이지를 눌러 선택합니다. 선택한 페이지는 위쪽 버튼으로 한꺼번에 회전하거나 삭제할 수 있고, 타일에 붙은 회전 버튼은 그 페이지 하나만 돌립니다.
  5. 전체를 하나의 PDF로 저장하면 병합이고, 원하는 페이지만 골라 저장하면 분할입니다. 두 버튼 모두 새 파일을 만들 뿐 원본은 건드리지 않습니다.
  6. 페이지를 이미지로 저장하면 화면의 두 배 해상도로 렌더링한 PNG가 ZIP으로 나옵니다. 문서 전체가 아니라 4쪽 그림만 필요하다고 할 때 씁니다.

lightbulb 알아두면 좋은 점

  • PDF 하나를 둘로 나누려면, 한 번 불러온 뒤 앞부분을 선택해 저장하고 선택을 뒤집어 다시 저장하면 됩니다. 원본은 그대로 남습니다.
  • 회전은 페이지가 원래 갖고 있던 각도 위에 더해집니다. 처음부터 옆으로 누워 있던 페이지도 썸네일에 보이는 그대로 저장됩니다.
  • 이미지는 이미지 크기에 맞춘 한 페이지가 됩니다. 휴대폰 사진 여러 장을 넣으면 장마다 흰 여백이 생기지 않고 문서가 만들어집니다.
  • 문서는 400페이지까지만 다룹니다. 그 이상은 썸네일만으로 탭 메모리가 바닥나므로, 파일을 먼저 나눠서 부분별로 처리하시는 편이 낫습니다.
  • 암호가 걸린 PDF는 암호를 풀기 전에는 읽을 수 없습니다. 브라우저가 암호를 알아낼 방법은 없고, 이 도구는 조용히 실패하는 대신 그 사실을 알려 줍니다.

help_outline 자주 묻는 질문

파일이 서버로 올라가나요?

올라가지 않습니다. 파일은 이 탭에서 도는 자바스크립트가 직접 읽고, 새 PDF도 컴퓨터 메모리 안에서 만들어집니다. 받을 서버도, 저장해 둘 계정도 없습니다. 말만 믿기 어렵다면 파일을 놓기 전에 개발자 도구의 네트워크 탭을 열어 두고, 아무 요청도 나가지 않는 것을 직접 확인하시면 됩니다.

화질이 떨어지나요?

PDF 페이지는 떨어지지 않습니다. 병합은 페이지를 다시 그리는 게 아니라 원본 페이지 객체를 그대로 복사합니다. 글꼴도, 벡터도, 안에 들어 있던 이미지도 원본 그대로이므로 선명하게 들어온 페이지는 선명하게 나갑니다. 화질을 따져야 하는 건 픽셀로 다시 그리는 "이미지로 저장" 쪽뿐이고, 그쪽은 화면의 두 배 해상도로 렌더링합니다.

합친 파일이 원본 합보다 큰데 왜 그런가요?

페이지가 자기 자원을 함께 데려오기 때문입니다. 같은 글꼴을 쓰는 문서 두 개를 합치면 그 글꼴이 결과 파일에 두 벌 들어갑니다. 대신 아무것도 손실되거나 다시 인코딩되지 않습니다. 용량 계산이 깔끔하지 않은 대가로 원본 품질을 지키는 셈입니다.

PDF 안의 글자를 고칠 수 있나요?

아니요. 이 도구는 페이지 단위로 동작합니다. 순서 바꾸기, 회전, 삭제, 합치기까지입니다. 페이지 안의 문장을 고치려면 레이아웃을 다시 흘리고 글꼴을 대체하고 콘텐츠 스트림을 다시 써야 하는데, 그건 완전히 다른 종류의, 훨씬 무거운 도구입니다. 글자를 빼내는 게 목적이라면 이미지로 내보낸 뒤 OCR을 거치는 편이 빠릅니다.

휴대폰에서도 되나요?

됩니다. 다만 데스크톱이 편합니다. 터치로 선택하고 순서를 바꾸는 것도 되고 저장 결과도 같습니다. 큰 문서가 더 부담스러운 건 단순히 휴대폰 탭이 썸네일을 그려 둘 메모리가 적기 때문입니다.
