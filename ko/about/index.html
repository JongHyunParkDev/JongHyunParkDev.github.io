사이트 소개

WebTools는 브라우저 안에서만 동작하는 작은 도구들을 모아 둔 개인 사이트입니다. 한국에서 일하는 소프트웨어 개발자 박종현이 혼자 만들고 관리하며, 뒤에 회사나 팀, 투자자가 있지 않습니다.

왜 만들었는가

여기 있는 도구는 대부분 제가 쓰려고 찾다가, 믿고 쓸 만한 것이 없어서 직접 만든 것들입니다. 퍼센트 계산 하나에 추적 스크립트가 딸려 오고, 배경을 지워 보려면 먼저 회원가입을 해야 하고, PDF 두 장을 붙이려고 계약서를 남의 서버에 올려야 하는 식이었습니다. 그런데 그 일들은 전부 사칙연산이거나 이미지 처리이고, 브라우저가 이미 오래전부터 혼자 할 수 있는 작업입니다.

그래서 이 사이트의 모든 도구는 여러분의 기기 안에서 돌아갑니다. 서버도 데이터베이스도 업로드 단계도 없습니다. 사용하는 동안 개발자 도구의 네트워크 탭을 열어 두면 파일이 나가지 않는다는 것을 직접 확인할 수 있습니다. 사이트 전체가 이 한 가지 원칙 위에 만들어져 있고, 도구가 전부 무료인 이유이기도 합니다. 정적 파일 몇 개를 올려 두는 것 외에는 운영 비용이 들지 않기 때문입니다.

어떻게 만들었는가

사이트 전체가 정적 페이지로 만들어져 GitHub Pages에서 제공됩니다. 브라우저가 이미 제공하는 기능이 있으면 — 해시는 Web Crypto, 받아쓰기는 Web Speech, 시간대와 숫자 서식은 Intl, 이미지 작업은 canvas — 같은 일을 하는 라이브러리를 따로 싣지 않고 그것을 씁니다. 페이지가 가벼워지고, 여러분이 무엇을 하는지 들여다보는 제3자가 줄어듭니다.

도구마다 페이지 안에 설명 글이 붙어 있습니다. 그 도구가 무엇을 계산하는지, 어떻게 쓰는지, 그리고 어디서부터는 도움이 되지 않는지를 적어 둔 글입니다. 분량을 채우려고 쓴 글이 아닙니다. 실제로 계산을 하는 도구 — 퇴직금과 주휴수당, 대출 상환 스케줄, BMI 수치 — 는 근거가 되는 규정에 맞춰 검산했고, 그 규정에 기준일이나 한도 금액이 걸려 있으면 설명 글에 그 숫자를 그대로 적어 두었습니다. 지금도 유효한 기준인지 직접 확인하실 수 있게 하기 위해서입니다.

하지 않는 것

가입을 요구하는 도구는 없고, 가입할 것 자체가 없습니다. 여러분이 입력하거나 연 내용은 저에게 전송되지 않습니다. 다시 방문했을 때 남아 있는 설정 — 세계 시계에 추가한 도시, 계산기 기록 같은 것 — 은 여러분 브라우저 저장소에 있고, 사이트 데이터를 지우면 함께 사라집니다.

또한 이 도구들은 전문가의 판단을 대신하지 않습니다. 급여·퇴직금 계산기는 각 설명 글에 적힌 기준일 시점의 한국 노동관계법 계산식을 구현한 것이지, 여러분의 개별 근로계약에 대한 유권해석이 아닙니다. BMI 페이지가 돌려주는 값은 보건 당국이 집단을 볼 때 쓰는 지표이지 진단이 아닙니다. 결과가 중요한 사안이라면, 이 사이트는 남이 준 숫자를 한 번 검산해 보는 용도로 쓰시는 편이 맞습니다.

운영 재원

사이트는 Google AdSense 광고를 싣고 있고, 그것이 유일한 수입원입니다. 광고 수익은 도메인 비용과 도구를 손보는 시간에 쓰입니다. 어떤 도구도 유료화되어 있지 않으며, 광고주 때문에 특정 도구를 더 위에 놓거나 추천하거나 다르게 서술하는 일은 없습니다.

분석 도구는 Google Analytics 하나만 씁니다. 어떤 도구가 실제로 쓰이는지를 보고 무엇을 개선할지 정하기 위해서입니다. 각 서비스가 무엇을 수집하는지, 맞춤 광고를 어떻게 끄는지는 개인정보처리방침 페이지에 적어 두었습니다.

언어

사이트는 영어와 한국어로 발행합니다. 예전에는 일본어와 중국어 판도 있었지만 내렸습니다. 그 두 언어의 설명 글이 읽을 만한 분량에 못 미쳤고, URL 자리만 차지하는 페이지는 그곳에 도착한 사람에게 아무것도 해 주지 못하기 때문입니다. 기존의 일본어·중국어 주소는 오류 대신 해당 영어 페이지로 연결됩니다.
