What is this?

A collection of small, focused tools for people who build things for the web — the ones you end up searching for mid-task, then closing again five minutes later. Every one of them runs entirely in your browser: no account, no upload, no usage limit, and nothing you paste ever reaches a server.

What is in here

build Tools
General-purpose tools: a world clock with a meeting planner, a scientific calculator, text-to-speech and dictation, Markdown conversion, and QR code and barcode generation and scanning.
account_balance_wallet Pay & Money
pages.main.about.money
casino Simulators
Simulators: run a lottery draw thousands of times over and watch what the odds actually look like, rather than being told the number.
terminal Dev Tools
Everyday developer utilities: format and validate JSON, decode a JWT, read a cron expression, generate types from an API response, convert a cURL command into code, hash a file, or look up what a 422 actually means.
brush Design
Visual work: check colour contrast against WCAG, build a layered box shadow or gradient, compress images to WebP, and generate a full favicon set from one source image.
smart_toy AI
An AI reading that combines MBTI with Korean saju, for entertainment.

Keyboard shortcuts

Press Ctrl+K (or ⌘K on a Mac) anywhere to open the command palette and jump straight to a tool. A bare / does the same. Arrow keys move, Enter opens, Escape closes. Star a tool to pin it to the sidebar.

Why everything runs locally

These tools process the kind of data you should not be pasting into a stranger’s server: production JSON, access tokens, customer records, internal config. Doing the work in JavaScript on your own machine removes that question entirely — you can verify it by opening your network tab and watching nothing happen.
