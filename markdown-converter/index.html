Markdown Html Converter

Convert Markdown to HTML and HTML back to Markdown, with a live preview — for moving content between a CMS, a README and an email.

Conversion runs both ways, and the two directions have different failure modes. Markdown to HTML is well defined. HTML to Markdown is lossy by nature: Markdown has no syntax for a colspan, a nested table or a styled span, so a converter has to decide what to keep as inline HTML and what to discard.

This page keeps the structures Markdown can express — headings, lists, tables, links, code blocks, blockquotes — and preserves the rest as inline HTML rather than silently deleting it. That makes it usable for the common job of turning a copied web page or a Word export into something a README or a wiki will accept.

list_alt How to use Markdown Html Converter

  1. Paste Markdown on one side or HTML on the other.
  2. Watch the conversion and the preview update.
  3. Copy whichever format you need.

lightbulb Tips & gotchas

  • HTML to Markdown is inherently lossy: styling, classes and layout markup have no Markdown equivalent and are dropped. Check the result before publishing.
  • The preview is the fastest way to catch a broken table or an unclosed code fence.
  • Markdown flavours differ. Tables, task lists and strikethrough are GitHub extensions, not part of the original spec, so not every renderer supports them.

help_outline Frequently asked questions

Which Markdown flavour is used?

CommonMark with the common GitHub extensions, which is what most tools and static site generators expect.

Is raw HTML inside Markdown preserved?

Inline HTML is passed through when converting to HTML. When converting back, unsupported elements are simplified or dropped.

Can it convert a whole file?

Paste the contents into the editor; conversion works on text rather than files.
