ホームchevron_right開発ツールchevron_rightケース変換 & テキストツール

一度貼り付ければすべての表記法が同時に出ます。フィールド一覧をデータベースと JSON API、TypeScript のモデルの間で移すときのように、層ごとに違う表記を求められる場面で使います。

list_alt ケース変換 & テキストツール の使い方

  1. 左にテキストや識別子の一覧を貼り付けます。1行に1つが最も扱いやすい形です。
  2. 右で14種類の変換結果を確認します。入力と同時に更新されます。
  3. 行のアイコンで1つだけコピーするか、すべて書き出しで全変換をテキストファイルとして受け取ります。
  4. 変換の前に行ツールで並べ替え、重複削除、空白整理、番号付け、引用符処理ができます。

lightbulb 知っておくと便利なこと

  • 行ごとをオンにしておくと各行が独立して変換されます。カラム一覧を扱うときはこれが望ましい動作です。オフにすると全体を1つの文として扱います。
  • 略語を認識するので HTTPResponseCode は h_t_t_p_response_code ではなく http_response_code になります。
  • 入力形式が揃っている必要はありません。camelCase、snake_case、kebab-case、ドット、空白が混在していてもすべて正しく分割します。
  • 引用符 + カンマは、ふつうの一覧をそのまま貼り付けられる配列リテラルに変えます。

help_outline よくある質問

英語以外のテキストも扱えますか?

はい。単語分割に Unicode の文字・数字クラスを使うため、日本語や韓国語、アクセント付きラテン文字が失われずに保持されます。大文字小文字の変更は該当する文字にのみ適用されます。

kebab-case と url-slug は何が違いますか?

ほぼ同じですが、url-slug は前後の区切り文字も取り除きます。タイトルから URL のパスを作るときに必要な処理です。

入力内容はアップロードされますか?

いいえ。すべての変換はブラウザ内の JavaScript で処理されます。サーバーに送信されることも保存されることもありません。

このページの機能はすべてブラウザ内で動作します。登録もアップロードも利用制限もありません。
