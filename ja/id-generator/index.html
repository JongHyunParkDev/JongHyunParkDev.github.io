UUID v4、UUID v7、ULID、Nano ID をまとめて生成します。データベースのシード、テストの作成、フィクスチャの用意に使います。

list_alt ID ジェネレータ の使い方

  1. 識別子の形式を選びます。
  2. 必要な数を指定します。
  3. 生成して一覧をコピーします。

lightbulb 知っておくと便利なこと

  • UUID v4 は完全な乱数で順序がありません。UUID v7 と ULID はタイムスタンプを先頭に持つため生成順に並び、データベースのインデックスが断片化しにくくなります。
  • Nano ID は衝突耐性が同等でありながら UUID より短いため、URL に入れるのに向いています。
  • URL に出たり読み上げたりする ID なら、ハイフン入りの UUID より ULID や Nano ID のほうが扱いやすくなります。

help_outline よくある質問

主キーとして使っても大丈夫ですか?

大丈夫です。ただし大きなテーブルでは v4 より UUID v7 か ULID を選んでください。時系列の接頭辞のおかげで挿入時のインデックス局所性がはるかに良くなります。

重複することはありますか?

現実的な規模では確率は無視できます。ここのすべての形式は暗号学的乱数を使っています。

セキュリティトークンとして使えますか?

UUID は推測しにくい識別子としては適切ですが、権限とは無関係です。秘密鍵や API キーにはエントロピーが明示された専用の生成器を使ってください。

このページの機能はすべてブラウザ内で動作します。登録もアップロードも利用制限もありません。
