このサイトについて

Web を作る人のための、小さくて用途のはっきりしたツール集です。作業の途中で検索して使い、5分後には閉じる——そういうツールばかり集めました。すべてブラウザ内で動作し、アカウント登録もアップロードも利用制限もありません。貼り付けた内容がサーバーに送られることもありません。

収録しているもの

build ツール
汎用ツール：会議時間を調整できる世界時計、関数電卓、読み上げと音声入力、Markdown 変換、QR コードとバーコードの生成・読み取り。
casino シミュレーター
シミュレーター：ロトの抽選を何千回も回してみます。確率を数字で聞くのではなく、実際どう出るのかを目で確かめられます。
terminal 開発ツール
開発者向けツール：JSON の整形と検証、JWT のデコード、cron 式の読み解き、API レスポンスからの型生成、cURL コマンドのコード変換、ファイルのハッシュ計算、HTTP 422 の正確な意味の確認まで。
brush デザイン
デザイン作業：WCAG に沿った配色コントラストの検証、多層 box-shadow やグラデーションの作成、画像の WebP 圧縮、1枚の画像からファビコン一式の生成。
smart_toy AI
MBTI と四柱推命を組み合わせた AI 相性診断（エンターテインメント用途です）。
sports_esports ゲーム
ビルド待ちの合間に遊べるブラウザゲーム：スイカゲーム、陣取り、記憶合わせ、マインスイーパ。

キーボードショートカット

どこでも Ctrl+K（Mac は ⌘K）を押すとコマンドパレットが開き、目的のツールへ直接移動できます。/ キーだけでも同じです。矢印キーで移動、Enter で開く、Esc で閉じる。星を押すとサイドバーにピン留めされます。

すべてローカルで動く理由

これらのツールが扱うのは、本来他人のサーバーに貼り付けるべきでないデータです。本番の JSON、アクセストークン、顧客情報、社内設定など。自分の端末上の JavaScript で処理すれば、その心配自体がなくなります。ネットワークタブを開けば、通信が一切発生しないことをご自身で確認できます。
